# Frontend Mini-Challenges – SMART GOAL 60%

## Implementation Approach

- Built four pages: Image Gallery, Accordion, Stepper, and Password Strength Checker
- all challenges from the frontend-mini-challenges repository
- Implemented each pages with React hooks useState for state management
- Created a dashboard page to showcase all completed challenges
